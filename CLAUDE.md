# Sambhav Website

React + Vite site for a student-led initiative. Multi-page with React Router v6.
The site is built around **Start a Chapter** (`/start`) as the primary action and **Donate**
(`/donate`, GoFundMe) as the secondary one. Sambhav grows through high-school chapters and is
**not yet a registered 501(c)(3)** — never claim registered/charitable/tax-deductible status.

## ⚠️ Design source of truth (read before adding/editing any page)

The visual design == the **current single-page look**, and lives ONLY in:
- `src/index.css` — design tokens (`:root` custom properties) + global classes
  (`.section*`, `.container`, `.btn*`, `.grid-2/3/4`, `.card*`, `.stat-block*`, `.eyebrow*`)
- `src/pages/Home.css` — the canonical **section styles** (`.hero*`, `.mission__*`, `.map-section__*`,
  `.about-split`, `.pillar*`, `.place-card*`, `.donate-*`). New pages import `./Home.css` to reuse these.
- `src/pages/Contact.css` — token-based **form styles** (`.contact-form*`, `.contact-hero*`,
  `.contact-info*`). Pages with a form (Start a Chapter, Contact) import this.
- Component CSS: `Header.css`, `Footer.css`, `LearningHero.css`, `IndiaMap.css`, `Accordion` (uses globals).

**Build every page by composing these existing classes. Do NOT author new visual design, and do NOT
change `src/index.css` tokens.** If a page needs a layout, reuse a global/Home.css class first.

### History guardrail — do not resurrect old drafts
On **Jun 10 (`108d98b`)** the site was deliberately redesigned from an early multi-page build into a
single page and the router was removed. The old Jun-3 multi-page draft pages (`ProjectVidya`, and the

## Structure — routes (one file per page in `src/pages/`)
| Route | Page | Nav |
|---|---|---|
| `/` | `Home.jsx` — hero carousel + promo video + counters + mission teaser + LearningHero + get-involved | — |
| `/campaigns/learning-kits` | `campaigns/LearningKits.jsx` — the one running campaign | Campaigns ▾ |
| `/mission` | `Mission.jsx` | Mission |
| `/impact` | `Impact.jsx` — counters + ImpactMap | Impact |
| `/about` | `About.jsx` — founder + values | About |
| `/partnerships` | `Partnerships.jsx` | Partnerships |
| `/start` | `StartChapter.jsx` — **primary CTA** + application form | [Start a Chapter] |
| `/donate` | `Donate.jsx` — GoFundMe widget | [Donate] |
| `/contact` | `Contact.jsx` — form (footer link) | footer |
| `*` | `NotFound.jsx` | — |

`/start-a-chapter` redirects to `/start` (flyer/QR alias).
`/campaigns` redirects to `/campaigns/learning-kits` (no index page for a list of one).

The **Campaigns** nav item is a dropdown. Learning Kits is a link; **Teaching** and **Access** are
rendered `aria-disabled`, are not anchors, and carry a visible "Planned" tag. Do not turn them into
links until those campaigns actually exist.

- `src/components/` — Header, Footer, Accordion, JaliDivider, ScrollReveal, LearningHero,
  **HeroCarousel**, **PromoVideo**, **ImpactCounters**, **ImpactMap** (+ `ImpactMapStatic`),
  **Picture**, PSAModal (unused, kept for a future story-video), `_reserved/` (see below).
  `IndiaMap/` is **superseded** by `ImpactMap/` and is no longer imported anywhere.
- `src/data/media.js` — the media manifest. **No component hardcodes an image path**; add images here.
  Derivatives live in `public/media/` as `<slug>-<width>.<avif|webp|jpg>` at 480/960/1440/2000,
  regenerated by the build-time pipeline (Python + Pillow, not an npm dependency). Nothing is
  upscaled past its native size and no single file exceeds 400 KB.
- `src/data/geo.js` — OpenStreetMap boundary geometry, fetched once and committed so the map makes no
  runtime network call. **ODbL: the "© OpenStreetMap contributors" credit on the map is required.**
  Narasaraopet has a real polygon (relation 10160545, admin_level 6, i.e. the *mandal*, not the town
  limit). Ammanabrolu has **no** OSM polygon and renders as a point plus a radius ring; do not hand
  draw a substitute outline.
- `src/assets/brand/` — mark, lockup and wordmark SVGs, traced from the supplied raster screenshots
  and recoloured to the existing tokens. Cream ("light") variants exist because the ink trunk measures
  1.13:1 on `--indigo-2` and vanishes on dark backgrounds.
- `src/hooks/useDocumentTitle.js` — per-route `<title>` + meta description (zero-dep). Every page calls it.
- `src/config.js` — `GOFUNDME_URL` / `GOFUNDME_SLUG` (giving channel)
- Routing: `main.jsx` mounts `<BrowserRouter>`; `App.jsx` holds `<Routes>` + `ScrollToTop`.

## Copy rules
- **No em dashes and no en dashes in user-facing copy.** Use periods, commas, colons or parentheses.
- Sentence case headings.
- The three impact figures are **separate and never merged**: students who received a kit, schools
  reached, cost per kit. "Students who received a kit" is not "students enrolled at partner schools".
- Every figure carries a visible "as of" date, and approximations stay approximate (the source says
  `1200 +` and `=$3.50`, so the site says "over 1,200" and "about $3.50").
- **Never** describe a gift as tax deductible: no 501(c)(3), no fiscal sponsor.
- Every number on the site traces to `Sambhav Proof Of Concept.docx.pdf`. If it is not in there, it
  does not go on the site; write `[NEEDS INPUT: ...]` instead.
- `Project Vidya` is a **dead name** from the abandoned Jun-3 draft. The campaign is **Learning Kits**.
